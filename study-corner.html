Coding & Software Development

Computer programming is an essential skill for creating innovative digital tools, interactive websites, and solving complex real-world problems.
It empowers creators to develop creative solutions and turn everyday ideas into powerful interactive applications.

Why I like it

  • Building functional projects and web applications from scratch provides immense creative satisfaction.
  • It continuously exercises logical problem-solving and critical thinking skills with every challenge.
  • The developer community is welcoming, active, and offers endless open-source resources to learn from.

How I study it

  1. Read official documentation and follow structured interactive tutorials daily.
  2. Write code hands-on by creating mini projects, styling with CSS, and experimenting with new layouts.
  3. Inspect and debug errors carefully using browser developer tools and console logs.

Words to know

Algorithm
A defined, step-by-step set of instructions or computational rules designed to solve a problem or complete a task.
Variable
A named storage container in a program that holds a data value which can be referenced and modified during execution.
Cascading Style Sheets (CSS)
A stylesheet language used for describing the presentation, layout, and styling of a document written in HTML.
